# Open WebUI response performance footer

This derivative image keeps the official Open WebUI `v0.9.4` backend and replaces only its
built frontend. The patch renders provider usage metadata beneath each completed assistant
response. llama.cpp `timings` fields are shown as prefill speed, decode speed, and context usage.

The upstream source is pinned to commit `f51d2b026f1b0e7283b15f093412be8b67d24770`.
