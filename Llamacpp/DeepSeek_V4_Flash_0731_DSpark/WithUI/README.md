# DSpark general chat UI

```bash
./start.sh
./health_check.sh
./stop.sh
```

This starts the DS4 base model and a dedicated Open WebUI. No SQL-specific
system prompt is injected. On one 128 GB Spark the validated default is SSD
streaming with DSpark speculation disabled. The UI is available at
`http://127.0.0.1:3000` on the DGX.
